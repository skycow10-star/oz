# 《오즈의 마법사》 장 구성 (2026-11-21 선생님과 확정)

## 공통
- 주제: **이미 가진 힘을 알아보기** + **관계**. 원작(1900, 바움)을 따르며 1939년 영화 요소(빨간 구두 등)는 쓰지 않음.
- 하트(관계): 🐶 토토(처음 3), 🌾 허수아비, 🪓 양철 나무꾼, 🦁 사자.
- 선택지 세 갈래: 📖 원작 / ✨ 상상 / 🤝 함께(친구와 같이 해결).
- **힘 카드**: 원래 이야기·쉬운 이야기 **둘 다**. 친구가 '없다'고 한 것을 사실은 보여 준 장면에서 💡 알아보기 활동 → 카드 획득. 원래 이야기는 근거 원문 문장까지, 쉬운 이야기는 그림 카드처럼 간단히. 8장 오즈의 선물 장면에서 모은 카드를 되짚음. 엔진 기능은 2장 작업 때 추가.
- 장마다 자유 쓰기 칸 하나(앤의 이름 짓기 자리).

| 하늘을 나는 집 | 토토가 들창문에 빠짐 | C2 예측: 귀를 잡아 끌어 올림 |
| | 몇 시간의 외로움 | C3 행동: 차분히 기다리다 잠든다 📖 / 토토를 안고 노래 🤝 / 상상의 여행 ✨ |
| 먼치킨 나라 | "고귀하신 마법사님!" | C4 말 걸기: "아무것도 죽이지 않았어요" 📖 / 무슨 일인지 묻는다 🤝 / 마법사인 척 ✨ |

| 석판·입맞춤 | 에메랄드 시로, 이마의 자국 | C6 말 걸기: "같이 가 주세요" 📖 / "길만 알려 주세요, 토토랑 갈게요" 🤝 / "마법을 가르쳐 주세요" ✨ |
